# MATS Grants — Research Proposal

> **Status:** application-research repository, Autumn 2026
>
> **Scope:** empirical AI alignment / mechanistic interpretability / science of scheming

This repository contains a source-controlled, evidence-first research proposal for MATS. The repository is intentionally structured as a research dossier rather than as a collection of unsupported claims.

## Current research thesis

Study whether controlled model-organism experiments can produce measurable, causally informative signatures of oversight gaming, alignment faking, and deceptive behaviour, and whether mechanistic analysis can distinguish genuine internal changes from prompt-induced or evaluator-induced artefacts.

## Important application constraint

MATS states that LLMs may not be used to write any part of an application unless a work test or form explicitly permits it. This repository can therefore be used for research planning, fact-checking, source management and drafting for the applicant's own review, but the applicant should not submit AI-generated application prose where MATS prohibits it. See the official Autumn 2026 FAQ for the current policy.

## Research hygiene

The proposal distinguishes:

1. established observations;
2. hypotheses;
3. experimental proxies;
4. speculative interpretations;
5. engineering ambitions that are not yet validated.

The primary goal is to reduce overclaiming and make every proposed result falsifiable.
